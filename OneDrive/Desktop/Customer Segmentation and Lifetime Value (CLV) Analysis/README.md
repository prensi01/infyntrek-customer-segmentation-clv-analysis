
# Customer Segmentation and Lifetime Value (CLV) Analysis

## Project Objective

Analyze customer purchasing behavior, segment customers using RFM
and K-Means clustering, and calculate historical Customer Lifetime Value.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SQL
- Jupyter Notebook
- Power BI

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. RFM Analysis
4. K-Means Customer Segmentation
5. Customer Profiling
6. Historical CLV Calculation
7. Customer Retention Analysis
8. Business Insights
9. Final Dashboard
10. Project Report

## Project Results

- Total Customers: 4,338
- Total Historical Revenue: 8,887,208.89
- Average Historical CLV: 2,048.69
- Inactive Customers: 33.40%

## Key Findings

- Total customers analyzed: 4,338.
- Total historical revenue: 8,887,208.89.
- Average historical CLV: 2,048.69.
- Median historical CLV: 668.57.
- Highest revenue segment: 2.
- Highest average CLV segment: 2.
- 33.40% of customers are classified as inactive using Recency > 90 days.
- Segment 2 contributes 63.12% of historical revenue.

## Limitations

Historical CLV is based on past customer spending and is not
a prediction of future customer revenue.

The dataset contains retail transaction data, not actual fintech data.
